# 圆圆搜索 (Yuanyuan Search)

一站式代码搜索聚合工具：一次搜索，同时聚合 **GitHub 仓库 / 网页 / Stack Overflow / npm 包** 四个来源的结果。

## ✨ 功能

- 🔍 **四源聚合**：GitHub 仓库、全网网页（360 + DuckDuckGo + Google + Bing）、Stack Overflow（中文自动翻译成英文再搜）、npm 包
- 📄 **结果不限量**：每源抓取最多 300 条（API 硬顶内尽量多抓），每页展示 10 条，翻页浏览全部
- 🌐 **内置代理**：软件自带代理内核，无需配置任何代理即可访问 GitHub 等国外站点
- 🧩 **自动兜底**：任一搜索源失败自动走镜像/备用通道，保证结果不断
- 🌙 深色模式 · 📌 收藏夹 · ⭐ 置顶窗口 · 📋 多选复制 · 💾 导出结果 · 📦 便携模式

## 🚀 安装

1. 下载安装包
2. 双击运行，一路「下一步」
3. 打开软件，输入关键词回车，四源结果同时展示

## 🖱️ 使用

- **双击结果**：用浏览器打开
- **右键菜单**：复制链接 / 复制标题 / 复制全部
- **搜索中**：标签页中央显示进度提示，可随时「取消」
- **窗口大小**：可自由缩放，翻页条在结果区底部

## 🛠️ 开发

- 源码：`tools/search_tool.py`（Python 3.10 + tkinter）
- 构建：`node tools/build-all.js`（自动版本号 +1 → PyInstaller → Inno Setup 打包）
- 环境：Windows 10/11 64 位
